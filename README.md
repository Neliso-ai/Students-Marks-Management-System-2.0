# Students-Marks-Management-System-2.0
A student management system that stores student information using JSON.  Features: 
✓ Add students 
✓ Delete students 
✓ Update student information 
✓ Update subject marks 
✓ Search students 
✓ Display all students 
✓ Persistent JSON storage 
✓ Error handling  
Technologies: - Python - JSON - File handling - Dictionaries - Functions - Exception handling
